# 시니어안심살핌 (senior-caresafe) - 모바일 현장 업무 지원 PWA

본 프로젝트는 고독사 예방 및 노인맞춤돌봄 현장 활동가(게이트키퍼, 생활지원사, 방문간호사)를 위한 **모바일 현장 전용 PWA**입니다.

## 1. 헌법 및 표준 거버넌스 문서 (필독)

본 프로젝트는 전사 표준 아키텍처에 의해 엄격히 관리됩니다. 코드를 수정하거나 기능을 추가하기 전 반드시 아래 문서들을 정독하고 준수하십시오:

1. **[AGENTS.md](.agents/AGENTS.md)**: AI 에이전트 및 개발자 절대 행동 강령 (사전 보고 승인제, 임의 코드 수정 금지, UID 불변성, ESM 모듈화)
2. **[HANDOVER_SENIOR_CARE.md](HANDOVER_SENIOR_CARE.md)**: 시니어안심살핌 (senior-caresafe) PWA 전용 인수인계서 및 앱2앱(S-GDS 연계) 규격 총괄
3. **[docs/전사_다중_프로젝트_통합_플랫폼_표준_아키텍처_총람_v05.md](docs/전사_다중_프로젝트_통합_플랫폼_표준_아키텍처_총람_v05.md)**: 전사 다중 프로젝트 통합 플랫폼 표준 아키텍처 총람 (단일 진실 공급원 - SSOT)

## 2. 프로젝트 핵심 아키텍처

- **앱2앱 (App-to-App) 딥링크 연동**: S-GDS 노인우울 선별조사 결과 데이터를 서버 경유 없이 모바일 딥링크(`?action=import_sgds&payload=...`)로 직접 수신하여 자동 기입.
- **오프라인 보안 에어갭**: 망 분리 및 통신 두절 환경을 위한 `.wrk` / `.json` 파일 반출/반입 지원 (보안 암호: `123456`).
- **테스트 단계 서버 격리**: 개발/테스트 중에는 외부 서버로 데이터를 무단 전송하지 않고 단말기 로컬 완결 동작 원칙을 고수.
- **UI/UX**: 모바일 터치 최적화 모던 슬레이트 디자인 시스템.
